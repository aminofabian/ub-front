Kiosk Till Print Bridge
=========================

Lets the cloud cashier print to a USB / local / network thermal printer
on THIS computer.

1. Unzip this folder completely (keep all files together).
2. Run the installer for your OS (below).
3. Return to Kiosk Cashier → Printer → Detect printers.

Windows 10 / 11 (install once — recommended)
--------------------------------------------
Double-click: Install-Kiosk-Print-Bridge.cmd
(Allow SmartScreen / Run anyway if prompted)

No Node.js is required.

That:
  - installs under %LOCALAPPDATA%\Palmart\till-print-bridge
  - starts the bridge hidden in the background
  - auto-starts at every Windows sign-in
  - tells Chrome / Edge to allow your Kiosk shop site to reach this PC
    (the "Local network access" prompt), so the cashier never sees it
  - looks for the receipt printer right away and saves it (config.json);
    Cashier picks it up with no Detect click
  - on Detect, adds an Xprinter / USB POS queue if Windows only shows
    the device in Device Manager (Generic / Text Only)

The one-file installer downloaded from Cashier (Install-Kiosk-Print-Bridge.cmd,
no zip) does all of the above and then opens Cashier for you.

You do NOT need to keep a window open while cashiering.
If http://127.0.0.1:19500/health says site can't be reached, double-click
Start-Bridge-Window.cmd and leave that window open, then try health again
on THIS PC (not another computer).

Manual start: start-till-print-bridge.cmd
Uninstall autostart: run Uninstall-Kiosk-Print-Bridge.ps1 in the install folder.

Confirm: open http://127.0.0.1:19500/health in the browser on this PC.

Windows 7
---------
This zip also includes the Win7 installer (no Node.js).
On Windows 7, run Install-Kiosk-Print-Bridge.cmd - it auto-switches,
or run Install-Kiosk-Print-Bridge-Win7.cmd directly.
See INSTALL-WINDOWS7.txt. Or download kiosk-till-print-bridge-windows7.zip.

macOS
-----

Double-click: Install Kiosk Print Bridge.command
(If macOS blocks it: right-click → Open)

Linux
-----
bash install-kiosk-print-bridge.sh

After install, the bridge listens on http://127.0.0.1:19500 and starts at login.
